# Groundwork — Visual process

A compact Hebrew RTL infographic on a light background. Six custom isometric SVG illustrations explain: understand → map → prioritize → execute → measure → embed. Click a step to reveal one short explanation. Escape or the close button dismisses it. Reduced-motion preferences are respected.

Open index.html directly, or serve the parent directory and visit /system/. No dependencies or network are required. The original Groundwork logo colors are preserved. The illustrations use vector depth rather than a 3D runtime.

Verified in the browser at 1440×900 and 390×844, including expanded explanation and dismissal. No horizontal overflow or console errors observed. Previous detailed process version is archived in the project outputs/groundwork-process-v2 directory. No public deployment performed.
